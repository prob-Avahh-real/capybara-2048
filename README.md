# 🌿 Capybara 2048 🌿

A fun, animated 2048 game featuring cute animal emojis that progress as you merge tiles!

## Features

- **Smooth Animations**: Tiles slide and merge with beautiful CSS transitions
- **Capybara Theme**: Each tile value has a unique animal emoji
- **Responsive Design**: Works on desktop and mobile devices
- **Touch Support**: Swipe to play on mobile devices
- **Score Tracking**: Current score and best score (saved locally)
- **Win Detection**: Celebrate when you reach 2048!
- **Continue Playing**: Keep going after winning to reach higher scores

## How to Play

1. Open `index.html` in a web browser
2. Use **Arrow Keys** or **WASD** to move tiles
3. On mobile, **swipe** in the direction you want to move
4. Combine matching tiles to merge them
5. Reach 2048 to win!

## Controls

- **Arrow Keys**: Move tiles up, down, left, right
- **WASD**: Alternative keyboard controls
- **Swipe**: Touch and swipe on mobile devices
- **New Game**: Click the button to restart

## Technical Details

- Pure HTML, CSS, and JavaScript (no dependencies)
- Local storage for best score persistence
- CSS animations for smooth tile movements
- Responsive grid layout
- Touch event handling for mobile
